# Восстановить проект и исправить запуск, паузу и сохранения

В main отсутствовали css/ и js/, в предоставленном полном архиве были
синтаксическая ошибка UI.bind() и CSS, не позволявший скрыть главное меню.
Из-за этого кнопки не приводили к работающему игровому процессу.

## Изменения

- Восстановлены модули/ресурсы из пользовательского архива без переписывания
  игровой концепции; сохранён исходный коммит соавтора.
- Three.js 0.159.0 хранится локально вместе с MIT-лицензией.
- Загрузчик показывает реальный прогресс этапов, ошибки HTTP/MIME, тайм-ауты
  и повтор. Меню доступно только после инициализации.
- Исправлены синтаксис UI, скрытие меню, пауза/таймеры боя, возврат из
  подэкранов, сумма/сохранение наград, сундуки, финал и повреждённые сохранения.
- Существующая прокачка за 5 артефактов доступна из инвентаря; добавлено обучение.
- Освобождаются старые геометрии/материалы и окружения, скрытая вкладка не рендерится.
- Яндекс SDK отделён адаптером, /sdk.js только в yandex-сборке.

По решению пользователя сохранён прежний внешний вид. Новые Figma-макеты
не внедрены и требуют согласования.

## Проверка

Playwright/Edge 154: desktop и 390×844, все меню, создание героя/бой, пауза,
возврат из подэкранов, награды, сундук, экипировка, buy/sell, levelUp,
save/reload, поражение/retry/previous, boss transition, dragon final/restart,
повреждённое сохранение, отсутствие внешних запросов, 404/retry.
Нулевое число необработанных JS-ошибок. SDK call order и SDK pause — на stub.
Launcher check проходит; ZIP около 197 КБ, менее 100 МБ без сжатия.

Осталось: настоящая консоль Яндекс Игр/модерация, реальные мобильные устройства,
профили производительности, длительный баланс 80 уровней, локализация и музыка.
Steam не переносился. Подробности в docs/VALIDATION.md.
