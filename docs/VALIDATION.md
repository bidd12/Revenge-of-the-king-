# Проверка сборки

Сохранён внешний вид из пользовательского архива. Предложение Figma не внедрено:
пользователь выбрал сохранить прежнее оформление и согласовывать дизайн заранее.

## Подтверждённые причины

- GitHub main содержал только index.html, README.md, launcher.py и run.bat.
  Модули и CSS восстановлены из пользовательского revenge-of-the-king-v3-fixed-menu.zip.
- В UI.bind() была лишняя скобка после настройки музыки.
  Браузер отклонял UI и весь граф зависимостей main.js.
- CSS #menuScreen display:flex!important перекрывал .hidden.
- Three.js зависела от внешнего CDN. Библиотека 0.159.0 и MIT-лицензия
  теперь в vendor/. GLTF/OBJ-загрузчиков в коде нет: модели процедурные.

## Изменения

Загрузчик проверяет обязательные CSS/JS, MIME и HTTP-статус, загружает локальную
Three.js, импортирует модули, подключает платформенный адаптер. Прогресс отражает
этапы, а не размер скачанных байтов. Ошибки и тайм-ауты показываются
до доступа к меню. Повтор после частичной инициализации перезагружает страницу.

Бой останавливается в паузе и скрытой вкладке; отложенные атаки и кровотечение
не переходят к другому врагу/герою. Возврат из инвентаря, карты и магазина
сохраняет бой. Space не атакует при вводе имени. Исправлены сумма награды,
сохранение монет и счётчика предметов, обязательное открытие сундука,
проверка сохранений и продолжение после поражения/финала.

Существующая levelUp подключена к инвентарю: 5 артефактов повышают уровень
и восстанавливают здоровье. В описание локации добавлены цель и обучение.
В 3D исправлено освобождение геометрий/материалов и удаление старого окружения;
отрисовка приостанавливается в скрытой вкладке, поворот врага сбрасывается.

## Повторяемые проверки

Запустить HTTP-сервер из корня проекта, установить Playwright для Node и браузер:

    python -m http.server 8000 --bind 127.0.0.1
    node scripts/smoke.cjs
    node scripts/regression.cjs
    python launcher.py --check
    python scripts/build.py --platform browser
    python scripts/build.py --platform yandex

Использованы bundled Node/Python/Playwright и Edge 154 headless с программным
WebGL. PLAYWRIGHT_MODULE и BROWSER_PATH выбирают установленные зависимости.

Smoke: desktop и 390×844; все кнопки меню; создание героя/бой; пауза без урона;
возврат из подэкранов; сумма награды; reload; поражение/retry; повреждённое
сохранение; запуск без внешних запросов; 404 и повтор.
Regression: levelUp, сундук, экипировка, покупка/продажа, границы локаций/финал,
продолжение финала/restart; SDK ready/start/stop и пауза на тестовом SDK.
Ускоренные границы прогрессии не заменяют прохождение 80 уровней и оценку баланса.

## Яндекс Игры

browser ZIP работает локально без SDK. yandex ZIP добавляет data-platform="yandex"
и подключает /sdk.js хостинга Яндекс Игр. SDK не скачивается в проект.
LoadingAPI.ready вызывается после удаления загрузчика, GameplayAPI — на
переходах боя. Ошибки SDK показываются загрузчиком. Пауза SDK останавливает
бой/звук; возобновление — кнопкой игрока.

Официальная документация проверена:
- https://yandex.ru/dev/games/doc/ru/sdk/sdk-about
- https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events
- https://yandex.ru/dev/games/doc/ru/concepts/requirements
- https://yandex.ru/dev/games/doc/ru/console/add-new-game

ZIP: index.html в корне, имена ASCII без пробелов, менее 100 МБ до сжатия.

## Оставшиеся ограничения

Реальная консоль Яндекс Игр и модерация не проверены. Только русский язык,
localStorage без облачной синхронизации; музыка не реализована в оригинале.
Нужны реальные мобильные устройства, GPU-профилирование, длительное прохождение
и баланс всех классов. Новый дизайн требует согласования. Steam не переносился.
