# Месть королю

Полностью локальная браузерная Action RPG на HTML5, CSS3, JavaScript ES6+ и Three.js.

## Требования
- Windows для `run.bat`.
- Python 3.10+ для локального HTTP-сервера.
- Современный браузер с WebGL и ES-модулями.
- Интернет нужен только для 3D-сцены Three.js. Даже если CDN недоступен, меню и сама игровая логика запускаются без блокировки.

## Установка Python
1. Откройте официальный сайт Python.
2. Установите Python 3.10 или новее.
3. В установщике Windows включите `Add Python to PATH`.

## Запуск через run.bat
1. Распакуйте ZIP.
2. Откройте папку `revenge-of-the-king`.
3. Запустите `run.bat`.
4. Скрипт сначала запускает локальный сервер, затем автоматически открывает игру в браузере. Обычно это `http://localhost:8000`; если порт занят, будет выбран следующий свободный порт до 8009.

## Ручной запуск
Откройте терминал в папке проекта и выполните:

```text
python launcher.py
```

Лаунчер сам выберет свободный порт и откроет браузер.

## Остановка
В окне терминала нажмите `Ctrl+C`.

## Структура
- `index.html` — разметка интерфейса.
- `css/style-v3.css` — оформление.
- `js/main.js` — Three.js-сцена и запуск.
- `js/game.js` — игровой цикл.
- `js/player.js` — герой и классы.
- `js/combat.js` — бой.
- `js/enemies.js` — обычные враги.
- `js/bosses.js` — боссы.
- `js/items.js` — оружие, броня и редкости.
- `js/inventory.js` — инвентарь.
- `js/chests.js` — сундуки и pity system.
- `js/shop.js` — магазин.
- `js/locations.js` — 5 локаций.
- `js/levels.js` — уровни.
- `js/save.js` — LocalStorage.
- `js/ui.js` — интерфейс.
- `js/audio.js` — безопасный процедурный AudioManager.
- `js/utils.js` — вспомогательные функции.
- `assets/` — зарезервирована для будущих ассетов.

## Управление
- ЛКМ по кнопке `АТАКА` — удар.
- `Space` — атака как дополнительное удобство.
- `Esc` — пауза/меню.
- Мышь — интерфейс.

## Сохранение
Сохранение хранится в `localStorage` браузера под ключом `revenge_of_the_king_save_v1`.

Автосохранение происходит после боевых побед, получения предметов, покупок, продаж, экипировки, прокачки и переходов.

## Игровой контент
5 локаций × 16 уровней = 80 уровней. На уровнях 1–15 создаётся 3–5 врагов, уровень 16 — босс. После босса открывается следующая локация. После победы над драконом показывается финальный экран.

## Примечание о Three.js
Версия Three.js подключена через jsDelivr CDN. Все игровые 3D-модели строятся процедурно из Three.js-примитивов, поэтому отдельные модели и изображения не обязательны.

## Debug
В `js/utils.js` есть:

`export const DEBUG_MODE=false;`

Для разработки можно временно установить `true`. В обычной игре значение должно оставаться `false`.
